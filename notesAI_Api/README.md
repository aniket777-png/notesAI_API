# 🧠 AI Notes Application (Laravel + Redis + Semantic Search)

A smart backend-based Notes Management System built using Laravel that demonstrates AI-like features such as Semantic Search, Automatic Summarization, and Redis-based caching for high-performance API responses.

This project is designed for learning backend development with real-world scalable architecture concepts.

---

# 🚀 Project Overview

This project is a Notes Management System where users can:

- Create notes
- Edit notes
- Delete notes
- Fetch notes with pagination
- Search notes using AI-like semantic search
- Generate automatic summary of notes
- Improve performance using Redis caching

Instead of using paid AI APIs, this project implements custom logic-based AI features.

---

# ✨ Features

## 📝 1. Notes CRUD System
- Create new notes with title and content
- Update existing notes
- Delete notes
- Paginated listing of notes

---

## 🔍 2. Semantic Search (AI-like Search)

- Implements vector-based search (TF-IDF style logic)
- Converts text into frequency-based vectors
- Uses cosine similarity to match results
- Returns most relevant notes instead of exact keyword match

---



## 🧠 4. AI Summary Feature

- Generates short summary from note content
- Extracts important sentences
- Lightweight NLP-style processing without external APIs
